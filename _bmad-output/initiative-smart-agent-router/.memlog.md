# Decision Log: Smart Agent Router

- **Date:** 2026-11-05
- **Topic:** Agent Load Balancing, Cooldown Tracking & Telemetry
- **Author:** BMad

## Context
Developers working with multiple generative coding agents (`claude`, `agy`, `codex`) face rate limits and token/session quotas. An intelligent selection mechanism is required at worktree initialization time.

## Decisions

1. **Storage Location: Shared Git Metadata**
   - *Decision:* Store `agents_status.json` in `<git-common-dir>/sprout/agents_status.json`.
   - *Rationale:* Shared across all worktrees without duplicate state files, zero risk of committing secrets or local metrics to Git.

2. **Telemetry Source: Herdr Socket API**
   - *Decision:* Query `herdr agent list` or `herdr pane list` via CLI.
   - *Rationale:* Herdr is already running as the workspace multiplexer; querying its live daemon state provides instant process-level concurrency counts without any overhead.

3. **Routing Precedence: Explicit Override > Cooldown Check > Concurrency Load > Priority**
   - *Decision:*
     1. Explicit `--agent <NAME>` flag always wins.
     2. If `auto` (or default): Filter out agents with active `cooldown_until > now`.
     3. Select available agent with lowest active sessions; break ties by configured priority.
